# the packages.json has been added - this tells node.js all the libraries it needs for development and building
    react - for the user interface
    react DOM - displays the react components on the browser
    vite - runs the development server and builds the app for deployment
    typescript - this is used for catching the typos, mistakes and errors during development
    react router DOM - this lets users navigate the website between pages without reloading the whole app
    lucide react - provieds icons like menu, search and settings
    @types/react and @types/react-dom - Help TypeScript understand React
    @vitejs/plugin-react - Helps Vite work with React.
